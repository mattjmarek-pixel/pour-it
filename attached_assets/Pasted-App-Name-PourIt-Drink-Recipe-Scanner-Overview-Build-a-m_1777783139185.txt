App Name: PourIt — Drink Recipe Scanner
Overview:
Build a mobile-first React web app called PourIt that lets users scan or select a bottle/product and instantly get a curated list of drink recipes. The app supports three modes: Spirits (alcoholic), THC-infused beverages, and Mocktails. The design should feel premium, modern, and exciting — like a high-end cocktail bar met a sleek consumer app.

Tech Stack:

React + Vite
Tailwind CSS
Framer Motion (animations)
Google Fonts: "Playfair Display" for headings, "DM Sans" for body
No backend required — all recipe data is hardcoded in a JSON file


Design Direction:

Dark theme: deep near-black background (#0A0A0F), with rich amber/gold accents (#D4A843) for spirits mode, purple/violet (#7C3AED) for THC mode, and emerald green (#10B981) for mocktail mode
Each mode has its own accent color that flows through buttons, active states, card borders, and gradients
Full-bleed hero section at the top with a subtle animated gradient mesh background that shifts based on active mode
Cards use frosted glass effect (backdrop-blur, semi-transparent dark backgrounds, thin colored borders)
Smooth page transitions and card entrance animations using Framer Motion
Typography is bold and editorial — large display text, tight letter spacing on headings
Bottom tab navigation for the three modes with animated indicator


Core Features:

Mode Switcher (Bottom Nav)

Three tabs: Spirits 🍸 | THC 🌿 | Mocktails 🧃
Animated sliding indicator under active tab
Switching modes triggers a smooth crossfade transition and changes the app's accent color globally

Below the scan zone: "Or browse by category" section showing product category chips (Vodka, Rum, Gin, Tequila, Bourbon, etc. — changes per mode)
Tapping either the scan zone or a chip goes to the product selection screen


Product Selection Screen

Grid of product cards (2 columns), each with a large emoji, product name, and brand
Cards animate in with a staggered entrance (Framer Motion)
Selected card gets a glowing accent-colored border


Recipe List Screen

Header shows selected product name and a "Change product" back link
Recipe cards in a vertical list, each showing: recipe name, difficulty badge, time estimate, and flavor tags
Tapping a card expands it inline (accordion) with smooth height animation revealing: full ingredient list, numbered steps, and a "Customize with AI" button

Saved Recipes (optional tab)

Heart icon on each recipe card saves it to localStorage
Saved tab shows saved recipes across all modes
