## 3. HAPTIC FEEDBACK

expo-haptics is already included in Expo SDK 54 — no install needed.

Add to artifacts/pour-it/components/ProductGrid.tsx:
  import * as Haptics from 'expo-haptics';
  On product card press: Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light)

Add to artifacts/pour-it/components/RecipeList.tsx:
  On save/unsave toggle: Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium)
  On successful save: Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success)

Add to artifacts/pour-it/components/ScanView.tsx:
  On scan/tap trigger: Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Heavy)

Add to artifacts/pour-it/components/AIPanel.tsx:
  On stream error: Haptics.notificationAsync(Haptics.NotificationFeedbackType.Error)
  On stream complete: Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success)

Wrap every Haptics call in try/catch to silently no-op on simulators:
  try { await Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Light) } catch (_) {}
