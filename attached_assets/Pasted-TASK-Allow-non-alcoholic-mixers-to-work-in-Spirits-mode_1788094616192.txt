CONTEXT: Currently the cross-category safety gates require the scanned item's category to exactly match the active app mode (spirits/thc/mocktail). This incorrectly blocks non-alcoholic mixers (tonic water, orange juice, soda, syrup, brine, broth, etc.) from being scanned in Spirits or THC mode, even though mixers are just drink ingredients and pose no safety risk there. Separately, when a genuine cross-category mismatch IS correctly rejected (e.g. a THC product scanned in Spirits mode), the rejection currently gives no guidance on what to do next.

PART 1 — CATEGORY GATE LOGIC (replace exact-match with this 3-rule logic):
1. If item category is "thc" -> allow ONLY in THC mode. Reject in Spirits mode and Mocktails mode (unchanged behavior).
2. If item category is "spirits" (contains alcohol) -> allow ONLY in Spirits mode. Reject in Mocktails mode AND THC mode (unchanged — alcohol must never be allowed in THC mode; no alcohol+THC mixing recommendations).
3. If item is a safe, human-consumable, non-alcoholic, non-THC BEVERAGE (i.e., not spirits, not THC) -> treat it as a "mixer" and allow it in ALL THREE modes: Spirits, Mocktails, and THC.

Scope for rule 3 is limited to actual drinkable beverages (juices, sodas, waters, syrups, brines, broths, etc.) that already pass the existing "safe for human consumption" identification check. Do NOT extend this to non-liquid pantry ingredients (spices, pastes, powders) — that is an out-of-scope future/premium feature. If the four sequential hard gates in identify.ts determine the scanned item is not a real, safe, consumable beverage, it should still be rejected as before — this task only changes which app MODES a non-alcoholic beverage is allowed in, not what counts as safe.

Do NOT build a curated allowlist of "approved mixer types." Any beverage that passes the existing safety identification and isn't alcohol or THC qualifies. Unusual-sounding mixers (bone broth, pickle brine, savory or fermented ingredients) are not inherently excluded — real cocktail culture successfully uses ingredients like these (e.g. the classic Bloody Bull and Bullshot both use beef broth, dating back to the 1950s).
