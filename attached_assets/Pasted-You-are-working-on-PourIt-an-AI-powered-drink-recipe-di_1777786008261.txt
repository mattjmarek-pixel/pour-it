## 2. Fix Animations: Enable useNativeDriver

All animations currently use `useNativeDriver: false` for web compatibility, which severely degrades performance on native devices.

- Audit every `Animated` call in the codebase (especially in `ScanView.tsx`, `ProductGrid.tsx`, `RecipeList.tsx`, `AIPanel.tsx`).
- Switch all transform and opacity animations to `useNativeDriver: true`. These are the only properties that support native driver and they are already the ones being animated (fade-in, slide, scale).
- For any layout animations (width, height, top, left, backgroundColor) that cannot use native driver, either eliminate them, replace them with transform equivalents, or install and use `react-native-reanimated` (which handles both native and JS animations cleanly and is already compatible with Expo SDK 54).
- Do not break web compatibility if web is a real target — use `Platform.OS` guards or Reanimated's unified API.
